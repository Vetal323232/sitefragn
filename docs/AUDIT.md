# Аудит pshykrozpyv.com (15.11.2026)

Метод: публичные страницы, публичный WooCommerce Store API (`/wp-json/wc/store/v1/...`), гостевая корзина без оформления заказа (сразу очищалась), Playwright/Chromium. Доступа к админке, серверу и исходникам не было.
Обозначения: **Н** — наблюдение (проверено), **Г** — гипотеза, **П** — предложение.

## Находки по приоритетам

### P0 — мешает понять цену и покупку
1. **Н.** В карточках каталога и на главной указано «80 ₴ за 1 мл», но 1 мл купить нельзя (минимум 3). Реальная минимальная цена появляется только в меню объёма.
2. **Н.** На странице товара объём выбирается выпадающим списком; итог («240 ₴ за 3 мл») находится высоко над кнопкой, флакон — ниже кнопки, общей суммы «аромат + флакон» нет.
3. **Н.** В корзине у распива колонка «Кількість: 5» без единицы. На оформлении WooCommerce показывает «× 5» — читается как 5 штук.
4. **Н.** Не сказано, в какой таре приходит распив и что именно входит в цену. Фото — полноразмерные заводские флаконы.
5. **Н.** Счётчик «N Люди переглядають цей товар зараз» меняется при каждом запросе (14 → 20 → 18): это режим WoodMart со случайным числом. Данные не подтверждены.

### P1 — поиск, каталог, доступность
6. **Н.** Поиск без опечаток и транслитерации: «bacarat», «баккара», «Діор», «tomford», «lost chery» → 0 результатов.
7. **Н.** H1 главной — «Розпив» (подпись плитки); главный баннер — текст, впечатанный в картинку.
8. **Н.** Скрытое поле количества в разметке: `value="1" min="3"`. Пока JS не загрузился (WP Rocket откладывает его до первого касания), браузер молча блокирует «Додати в кошик».
9. **Н.** После смены объёма в корзине (например, 5 → 10 мл) флакон 5 мл остаётся в заказе — у позиций нет связи.
10. **Н.** Сообщения об остатке: «залишилось 3» без «мл».

## Г — гипотезы, которые стоит проверить владельцу
- Г1. Счётчик просмотров включён в WoodMart → Theme Settings → Single product → «Product visits count» с фиктивным диапазоном.
- Г2. Кнопка уведомления печатается без gettext (в HTML нет текстового домена). Плагин переводит её через gettext, а если это не сработает — через JS-резервный вариант.
- Г3. Высокий CLS главной — слайдер Elementor без зарезервированной высоты.
