# Передача владельцу / разработчику магазина

У автора этой работы был только публичный адрес сайта. Всё реализовано и проверено **локально**; на живом сайте ничего не менялось. Ниже — что нужно сделать человеку с доступом к админке.

## 1. Установка на staging (не на рабочий сайт)
1. Сделать копию сайта (Hostinger → Staging или плагин клонирования).
2. Загрузить папку `pshyk-boutique/` в `wp-content/plugins/` и активировать «Pshyk Boutique». Тему и плагины не трогает; обновления WoodMart, дочерней темы и `pshyk-rozpyv-store-functionality` ставятся как раньше.
3. WooCommerce → Pshyk Boutique: проверить тексты (особенно «Що входить у ціну»), задать `per_page = 24`, ID товаров подборки.
4. Создать страницу «Головна» с шорткодом `[pshyk_home]` (шаблон Elementor «Full width» или обычный). Посмотреть по её адресу, затем «Налаштування → Читання → Головна сторінка». URL `/` не меняется, редиректы не нужны.
5. WoodMart → Theme Settings:
   - выключить «Product visits count» (фиктивный счётчик);
   - в Typography заменить Montserrat на системный шрифт, чтобы не грузить два набора шрифтов (Montserrat ≈ 207 КБ против ≈ 64 КБ у новой пары).
6. WP Rocket: очистить кэш. Плагин сам исключает свой JS из «Delay JS» (фильтр `rocket_delay_js_exclusions`) — проверить, что кнопки объёма появляются без первого касания.
7. WPC Frequently Bought Together: положение блока можно оставить. Скрипт переносит блок флакона между объёмом и итогом; при желании задать «Above add to cart button».
8. Откат: деактивировать плагин. Данные, заказы и цены он не меняет.

## 2. Что проверить на staging (чек-лист)
- [ ] Товар: кнопки объёма совпадают с прежним выпадающим списком; итог = цена × мл + флакон; кнопка добавляет нужный объём.
- [ ] Флакон появляется для 5/10/15/20 мл, скрыт для 3 мл; в корзину попадает одна позиция флакона.
- [ ] Двойное касание «Додати в кошик» не создаёт второй декант (WoodMart AJAX: событие `added_to_cart`).
- [ ] Боковая корзина FunnelKit: шаг объёма работает как раньше.
- [ ] Каталог: «від … за 3 мл» совпадает с первым пунктом меню объёма в карточке.
- [ ] Поиск WoodMart: «bacarat», «баккара», «Діор», «tomford», «джо малон» находят нужное.
- [ ] Оформление тестовым способом оплаты: в заказе «5 мл» и мета «Об'єм: 5 мл». Посмотреть, как мета уходит в SalesDrive; если мешает — `add_filter( 'pshyk_boutique_order_volume_meta', '__return_false' );`.
- [ ] Остаток списывается в мл.

## 3. Вопросы, без ответа на которые нельзя выпускать (одним списком)
1. **Какая тара входит в цену распива по умолчанию** (стекло/пластик, атомайзер ли всегда)? Сейчас текст «стандартний атомайзер-розпилювач — він уже входить у ціну» выведен из того, что красивый флакон продаётся отдельно. Это нужно подтвердить.
2. Фото атомайзеров из баннера «Розпив» — это реальная тара магазина?
3. Магазин на фото в первом экране — какой из двух адресов? (Подпись нейтральная.)
4. Должен ли флакон 5 мл автоматически меняться при смене объёма в корзине (сейчас остаётся старый)?
5. Нужна ли метка «Об'єм» в позициях заказа для SalesDrive или там уже есть своя?
6. Какой шорткод ленты Instagram (Smash Balloon) показывать на новой главной — или оставить только ссылку (экономит ~180 КБ)?

## 4. Предложения на следующие этапы (не реализованы)
- **Подбор аромата** (5–6 вопросов: настроение, сезон, бюджет **за 3 мл**) с объяснением «почему этот» — на тех же группах ароматов, что и быстрые входы.
- **Конструктор набора** из доступных распивов (например, 4 × 3 мл) со скидкой по правилам магазина; проверка остатков на сервере.
- **Фильтр бюджета**: явно сравнивать «цену за 3 мл (мин. объём)», а не цену за 1 мл; реализовать через мета-поле минимальной цены, иначе сортировка будет по цене за мл.
- **Повтор заказа и статус**: кнопка «Замовити знову» в кабинете, публичная страница статуса по номеру + телефону, ТТН Новой Почты.
- **Для сотрудников**: печатная этикетка/пик-лист «аромат — мл — флакон» из заказа; связка «декант ↔ флакон» в корзине; шаблоны ответов на частые вопросы — они уже вынесены в FAQ и блок у кнопки.
- **Каталог**: оставить бесконечную загрузку, но порциями по 24 с настоящими ссылками `/shop/page/N/` для поисковиков.
- Перевести баннеры главной с текста-в-картинке на HTML-текст.
