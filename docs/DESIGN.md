# Визуальная концепция: «Лабораторія на кремовому папері»

Независимый бутик распива: тёплая бумага, графитовые «чернила», один сливовый акцент — продолжение чёрно-белого логотипа PSHYK_ROZPYV, но мягче и дороже. Типографика делает основную работу: крупная антиква Cormorant с курсивными акцентами для заголовков и спокойный гротеск Manrope для интерфейса и цен. Фотографии — реальные: магазин, атомайзеры, флаконы. Генерация изображений в этой среде недоступна, поэтому атмосферу дают композиция и шрифт, а не фоны.

Визуальная доска: [`screenshots/design-tokens.jpg`](screenshots/design-tokens.jpg), живая версия — [`design-tokens.html`](design-tokens.html). Источник истины — [`pshyk-boutique/assets/css/tokens.css`](../pshyk-boutique/assets/css/tokens.css).

## Решения
- **Не одинаковые карточки везде.** Настроения — нумерованный «индекс» с крупными словами; подборка — тёмная редакционная полоса со списком 01–08; отзывы — цитаты без рамок; шаги распива — крупные цифры. Карточки товаров есть только там, где нужно сравнивать товары.
- **Фото товара на «льняной» подложке** (`mix-blend-mode: multiply`): белые студийные фоны растворяются, сетка выглядит единой при разных исходниках.
- **Честный формат.** На первом экране есть плашка «Ви отримуєте розпив — атомайзер, а не повний флакон». Отдельная секция «Що приходить у посилці» показывает атомайзеры и опциональные флаконы с ценами из каталога.
- **Цена — крупно и за реальный объём**: «від 240 ₴ за 3 мл», цена за 1 мл — мелко ниже.

## Расхождения с заданием
- Генерация изображений недоступна, поэтому атмосферные фоны не делал. Сознательно: «бессмысленные градиенты» задание тоже запрещает.
- Фото конкретного атомайзера по умолчанию подписано «Приклад атомайзерів», пока магазин не подтвердит, какая тара входит в цену.
